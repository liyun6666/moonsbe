- 是否为移植项目：否，原创 MoonBit 实现，引用上游标准示例进行独立验证

**项目简介**

moonsbe 面向需要将 MoonBit 接入已有 SBE 消息系统的开发者，读取标准 XML Schema，提供二进制消息编解码、类型化代码生成和版本变化检查。项目适用于跨语言服务通信、已有二进制记录读取及消息定义升级验收，使其他 MoonBit 项目能够通过可复用 API 处理既有 SBE 数据。当前已发布 0.1.0，并完成与上游 Java 参考实现的双向互通验证。

**核心功能范围**

- 解析 SBE XML Schema，处理基础类型、枚举、位集合、复合类型、常量和显式提供的 XInclude 资源。
- 支持标准 8 字节消息头、双字节序、完整 64 位整数、浮点、嵌套重复组及可变长数据。
- 生成可编译的 MoonBit 结构体、枚举和编解码适配器，提供独立消费包示例。
- 校验数值范围、空值、消息截断及资源上限，按 acting version 和 blockLength 处理版本差异。
- 提供库 API、CLI、JSON 消息转换、Schema 变化检查和明确的兼容范围文档。
- 提供 38 个测试及持续集成，验证 Java 与 MoonBit 产生的官方 Car 样例消息共 207 字节且逐字节一致，保留可复现日志。
