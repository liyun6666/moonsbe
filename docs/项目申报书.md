**项目简介**

moonsbe 面向需要将 MoonBit 接入已有 SBE 消息系统的开发者，读取标准 XML Schema，提供二进制消息编解码、类型化代码生成和版本变化检查，为不同业务的 MoonBit 项目复用同一套协议处理能力。当前已发布 0.1.0，并完成与上游 Java 参考实现的双向互通验证。

**使用场景**

1. **跨语言服务接入**：已有 Java 服务发送 SBE 消息时，MoonBit 服务依据同一 Schema 生成类型、解码字段并编码响应，减少手写字段偏移和类型转换的工作。
2. **二进制记录检查**：开发人员提供已划定消息边界的文件或日志记录，通过 CLI 按 Schema 解码为 JSON，核对字段值，定位模板不匹配、越界或消息截断问题。
3. **消息定义升级验收**：团队比较新旧 Schema，在 CI 运行 Java 与 MoonBit 双向编解码，核对完整消息字节并保存日志，检查版本变化引入的兼容性问题。

**核心功能范围**

- 解析 SBE XML Schema，处理基础类型、枚举、位集合、复合类型、常量及显式提供的 XInclude 资源。
- 支持标准 8 字节消息头、双字节序、完整 64 位整数、浮点、嵌套重复组及可变长数据。
- 生成可编译的 MoonBit 类型及编解码适配器，提供独立消费包示例。
- 校验数值范围、空值、消息截断及资源上限，按 acting version 和 blockLength 处理版本差异。
- 提供库 API、CLI、JSON 转换及 Schema 变化检查；以 38 个测试和 CI 验证官方 Car 样例的 207 字节消息与 Java 参考实现逐字节一致。
